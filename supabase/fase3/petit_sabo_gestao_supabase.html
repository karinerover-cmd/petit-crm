📗 Backup completo em Excel (.xlsx)
Baixa 3 arquivos CSV (Estoque, Vendas e Clientes). Abra no Excel e organize em abas na mesma planilha.
Para restaurar: abra o .xlsx, copie os dados de cada aba e use o botão Restaurar backup (.json) com o arquivo JSON correspondente — ou use as abas como referência para recadastrar manualmente se necessário.
☁️ Google Sheets — Sincronização
Cole o URL do seu Apps Script para sincronizar dados com o Google Sheets. Seus dados ficam salvos na nuvem e acessíveis de qualquer computador.
Sincronizar: envia dados locais para o Sheets e confirma.  |  Carregar: substitui dados locais pelos do Sheets.  |  Enviar: sobrescreve o Sheets com dados locais.
